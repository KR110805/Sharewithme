# 📚 ShareWithMe

> Built by students, for students.

ShareWithMe is a community-driven academic repository that enables students to organize, share, and discover study materials in one place. Instead of searching through WhatsApp chats, Google Drive links, and scattered folders, students can contribute resources to a centralized platform.

---

## 🚀 Features

- 📁 Create folders and subfolders
- 📄 Upload study materials
- 📚 Organize resources subject-wise
- 🔍 Search folders and resources
- 📂 Multiple file uploads
- 👥 Community-driven contributions
- 📝 Folder descriptions and notes
- 🔒 Admin management panel
- ☁️ AWS hosted deployment
- 📱 Responsive and modern UI

---

## 🎯 Problem Statement

Students often struggle to find academic resources because materials are scattered across:

- WhatsApp groups
- Personal drives
- Telegram channels
- Individual devices

As a result, useful notes, assignments, and PYQs get lost over time.

ShareWithMe solves this problem by providing a centralized repository where students can contribute and access resources collaboratively.
